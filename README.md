# Biological Dataset Selection: 1000 Genomes Project

## Dataset
1000 Genomes Project, Phase 3

## Source
International Genome Sample Resource (IGSR) - https://www.internationalgenome.org
Also available through NCBI and EBI.

## Size
- About 2,504 individuals from 26 populations
- About 84.7 million genetic variants
- Data files are in VCF format, split by chromosome

## Research Question
How does human genetic variation differ across global populations, and what can it tell us about ancestry and disease susceptibility?

## Why This Dataset
It is fully public, well documented, and needs no lab work. It is a foundational reference for population genetics.

## Possible Analysis
Compare allele frequencies between populations to find variants that are common in one group but rare in another.
